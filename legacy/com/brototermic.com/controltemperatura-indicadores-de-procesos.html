Modulo adquisición datos Sielco D1

Módulos de entrada salida que permiten la lectura de señales digitales y analógicas, medida de frecuencia, totalizador de pulsos y control on/off de aparatos externos. Todos los módulos están disponibles en carril DIN. La comunicación entre los módulos de entrada /salida y el sistema supervisor se basa en una comunicación serie RS-422/RS-485, con protocolo Modbus (ASCII o RTU). El software WINLOG, nos proporciona el interface para el operario en un entorno Windows para la supervisión en tiempo real.
